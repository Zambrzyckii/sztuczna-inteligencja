# Sztuczna inteligencja

Rozwiązania laboratoriów z przedmiotu Sztuczna Inteligencja. Każdy katalog to osobne zadanie w Pythonie.

## Zawartość

- `Lab1` – regresja liniowa (rozwiązanie zamknięte i spadek gradientu) na zależności MPG od masy pojazdu.
- `Lab2` – problem plecakowy: algorytm genetyczny (`for_students.py`) oraz rozwiązanie siłowe (`brute_force.py`).
- `lab3` – gra Connect Four z agentami przeszukującymi: `minmaxagent`, `alphabetaagent`, `randomagent` (tryby ava/avp/pvp).
- `lab4` – drzewo decyzyjne i las losowy na zbiorze Titanic.
- `lab5SI` – grupowanie metodą k-średnich na zbiorze Iris.
- `lab6SI` – sieci neuronowe: implementacja w NumPy oraz trenowanie w PyTorch.

## Uruchomienie

Każdy lab ma własny `requirements.txt`:

```
pip install -r <lab>/requirements.txt
python <lab>/<plik>.py
```
